# Simple Interest Calculator 🧮

Sebuah aplikasi kalkulator sederhana yang digunakan untuk menghitung nilai bunga tunggal (simple interest) dan total saldo akhir berdasarkan jumlah setoran awal (pokok), suku bunga tahunan, dan jangka waktu penyimpanan.

---

## 🔥 Fitur Utama

* **Hitung Bunga Instan:** Menghitung total keuntungan bunga secara *real-time* atau sekali klik.
* **Total Saldo Akhir:** Menampilkan akumulasi total dari modal awal ditambah hasil bunga.
* **Desain Responsif:** Tampilan yang bersih dan nyaman digunakan di perangkat *mobile* maupun *desktop*.
* **Validasi Input:** Memastikan pengguna tidak memasukkan nilai negatif atau format yang salah.

---

## 📐 Rumus yang Digunakan

Aplikasi ini menggunakan formula matematika standar untuk bunga tunggal:

1.  **Menghitung Nilai Bunga:**
    $$I = P \times r \times t$$

2.  **Menghitung Total Saldo Akhir:**
    $$A = P + I$$

**Keterangan:**
* $I$ = *Interest* (Total Nilai Bunga)
* $P$ = *Principal* (Modal/Setoran Awal)
* $r$ = *Rate* (Suku Bunga Per Tahun dalam bentuk desimal, misal: $5\% = 0.05$)
* $t$ = *Time* (Jangka Waktu dalam tahun)
* $A$ = *Amount* (Total Saldo Akhir)
